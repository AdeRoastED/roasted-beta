# RoastED v38 — Checklist for native speakers and language teachers

You are checking **language**, not technology. Use the **QA build** on any phone or computer.

## How to work
1. Tap 🧪 (bottom right) → choose **your native language → the language you check** → topic → level.
2. Switch on **"Also show the correct answer"** so you can check without guessing.
3. Tap a question in the list, or **Play these questions** to go through all of them.
4. For every problem tap **🚩 Report**: pick the problem type and write the correct version in the comment. The report contains the question ID, languages, options and app version automatically.
5. At the end: Settings → Reports → **Export all** and send us the file (or share each report directly).

Please report even small doubts — mark them "Other" and explain.

## What to check in every question
- [ ] The **question** (your native sentence) is natural and correct.
- [ ] The **correct answer** is a correct, natural translation — the way people really say it today.
- [ ] **Only one** option is correct. If another option could also be accepted, report "More than one answer is correct".
- [ ] The wrong options are really wrong, but believable (typical learner mistakes), not silly.
- [ ] Spelling, accents, capital letters, punctuation (French: no space before ? and !; German nouns capitalised; Thai spacing).
- [ ] **Thai only:** the romanization under each Thai answer matches the Thai text and is readable for a beginner.
- [ ] The **roast** (tutor's comment after a mistake) is in your language, makes sense, is funny-but-polite, and its grammar explanation is correct.

## What to check per area
- [ ] **Words** (greetings, adjectives, basic words, colours, time, pronouns, verbs, months, directions): one clear meaning, common everyday word.
- [ ] **Numbers** 0 → 2 billion written in words: spelling and the official rules (e.g. hyphens in French, "honderd-en-een" in Afrikaans, Thai เอ็ด/ยี่).
- [ ] **Grammar topics** (present, past, future, negation, questions): each level uses different verbs; conjugations and auxiliaries correct for every person (I, you, he/she, we, you plural, they).
- [ ] **Sentences** (food, travel, sports, culture, daily life): natural, not literal translations.
- [ ] **Conversations** (Beginner, Intermediate, Advanced — 8 each): the dialogue is natural; the correct reply fits; the "almost right" reply has exactly one wrong word; the rude reply is rude but acceptable for an app; Advanced uses formal language correctly (Sie / vous / Lei).
- [ ] **"What's new" pop-up** (shown once after updating): natural and correct.
- [ ] **Interface texts** (menus, trophies, daily goal, challenge, reports, ads/premium dialogs in the QA build, error messages): correct, natural, consistent words (always the same word for "level", "topic", "quiz"…).
- [ ] **Tutor character**: the voice matches the tutor (Nonna Rosa · Lord Sterling · Jean-Luc, vous · Hans, Sie · Oom Koos · ป้าส้ม, หนู/จ้ะ).
